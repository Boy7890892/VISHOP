# 🛍️ VISHOP - E-Commerce & Digital PPOB Platform

VISHOP adalah aplikasi e-commerce modern yang dilengkapi dengan layanan digital PPOB (Pulsa, Token Listrik, E-Wallet, dan Top Up Game) serta sistem autentikasi pengguna dan panel manajemen admin.

## 🚀 Fitur Utama
* **Autentikasi Pengguna**: Sistem Login & Register yang aman.
* **Manajemen Profil**: Unggah dan ubah foto profil kustom secara *real-time*.
* **Katalog Produk & Pencarian**: Filter produk berdasarkan kategori (Baru, Trending, Rekomendasi) serta fitur pencarian instan.
* **Layanan Digital PPOB**: Simulasi pembelian pulsa, token listrik, e-wallet, dan voucher game lengkap dengan sistem pembayaran QRIS & hitung mundur waktu.
* **Panel Admin**: Halaman khusus admin untuk menambah, mengelola, dan menghapus produk di etalase.

## 🛠️ Teknologi yang Digunakan
* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend**: Node.js, Express.js
* **Database**: Supabase (PostgreSQL)
* **Deployment**: Vercel
